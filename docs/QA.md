# Frontend verification

Run `npm test` for content preservation, calculator totals, contact validation, service selection and WhatsApp message integrity. Run `npm run build` to generate all 45 HTML pages and the static 404, sitemap and robots file.

Before publishing, inspect the production preview and verify the consultation modal, validation, WhatsApp handoff, calculator, filters and FAQ interactions. After publishing, check the live homepage, `.html` routes, images, security headers and 404 response. WhatsApp messages must not be sent during testing.

The form requires the visitor to send its prepared WhatsApp message. It does not claim that an enquiry has already been delivered. No API or database is required for any frontend interaction.
